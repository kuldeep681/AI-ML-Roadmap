# Phase 00 - Engineering Foundations

## Goal

Build the engineering fundamentals required for Machine Learning, AI Engineering, Cloud and MLOps.

**Estimated Duration:** 3–4 Weeks

---

## Why this Phase?

Before training ML models or building AI applications, you need to be comfortable writing clean Python code, managing projects, working with databases, using Git, and navigating Linux.

---

## Prerequisites

- None
